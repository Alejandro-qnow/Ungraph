Guía rápida

Esta página simula documentación con jerarquía y código para probar el CIR y el patrón FILE_PAGE_CHUNK.

Instalación

Instala el paquete con pip o uv en un entorno virtual.

uv pip install -e ".[crawl]"
python -c "import ungraph; print(ungraph.__version__)"

Configuración Neo4j

Configura la URI y la contraseña antes de ingerir.

  • Variable UNGRAPH_NEO4J_URI
  • Variable UNGRAPH_NEO4J_PASSWORD

Verificación

Tras la ingesta deberías ver nodos File, Page y Chunk conectados.
